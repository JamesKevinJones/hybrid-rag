# hybrid-rag console - agent context

The web UI for hybrid-rag. Read the repo root `AGENTS.md` first; this adds only
what is specific to `web/`.

Next.js 16 + React 19 + Tailwind v4 + TypeScript, `output: "export"`. No test
runner - `npm run build` is the real gate, matching portfolio-website.

## The two modes are the whole design

One artifact serves two hosts. `lib/client.ts` resolves the mode at **runtime**
from the hostname: localhost is live, anything else is demo. Baking it in at
build time would force two builds and guarantee the wrong one ships eventually.

`lib/api.ts` and `lib/fixtures.ts` implement the same `HybridRagClient`
interface, and `components/console.tsx` never knows which one it has.

**The demo is a recording, not a mock.** `fixtures/bundle.json` is generated by
`scripts/capture_web_fixtures.py` from real pipeline runs. **Never hand-edit
it.** Re-capture after any pipeline change that alters what it claims. A
hand-written number here would be the exact failure decisions 11, 15, 23, 27
and 31 all document.

It refuses unrecorded prompts rather than fuzzy-matching to the nearest
recording, because a matched answer shown as a live one is a fabrication.

## Rule 14 applies here

Nothing in `web/` decides, spends or logs. If a display needs a number the
pipeline does not produce, add it to `ExecutionResult` in Python - do not
derive a plausible one in TypeScript. Four values were plain `@property` and
silently vanished from the JSON until they were promoted to `@computed_field`;
that is the failure mode this rule exists to prevent.

The stage indicator is driven by real SSE events, never a timer. An indicator
on its own schedule is wrong in exactly the interesting case, where the guard
model is slow and the UI claims to be reranking.

## Type and layout

**Monaspace, self-hosted** via `next/font/local` over woff2 copied from
`@fontsource` into `app/fonts/`. Krypton for display, Argon for body, Neon for
labels. It is not on Google Fonts, and self-hosting also keeps a page whose
premise is "does not phone home" from making a third-party request.

The whole superfamily is monospaced, which is the point for a console - but it
runs ~15% wider than a proportional face, so display clamps are tuned lower
than they would be for Archivo.

`h1-h4` use `line-height: 1.12` and `letter-spacing: -0.01em`. The previous
`0.95 / -0.03em` came from a proportional face and, on Monaspace, clipped every
descender - the `g` in "budgeted" was cut off by the acid highlight behind it.
Do not tighten it back without looking at a descender under `.mark`.

**Layout is a chat client, not a page.** Header and the composer are fixed
chrome, the transcript scrolls between them, everything is centred to
`max-w-3xl`. The thesis and the status strip are the EMPTY STATE and step aside
once there is a transcript - a hero that stays put pushes the answer off screen.

The auto-scroll effect must stay guarded on `turns.length > 0`. Without it, it
fires on mount and scrolls the heading up behind the header, so a visitor lands
on a blank column.

## Motion

GSAP, inside `gsap.matchMedia()` so a reduced-motion visitor registers no
tweens at all rather than instant ones. Always `gsap.from()`, never `gsap.to()`
out of a hidden start state: the markup is visible by default, so a bundle
error leaves a readable page instead of a blank one.

`lib/motion.ts` holds the shared easing and an isomorphic layout effect - GSAP
has to set start values before paint, and this app is prerendered, where
`useLayoutEffect` warns.

## Design rules that are already load-bearing

- `@custom-variant dark (&:is(.dark *));` stays at the top of `globals.css`.
  Without it a dark-set OS renders light mode at 1.14:1 - invisible text.
- **Coral carries ink, never white.** 6.46:1 with ink; 3.05:1 with white, which
  fails AA. Only volt takes white, at 4.93:1. Measure, do not eyeball.
- **Muted text sits at `opacity-75`, not lower.** `opacity-55` on ink over
  paper measures 4.23:1, which fails AA for anything under 18.66px - and every
  HUD label and note is 11-13px. At 0.75 it is 8.56 light / 9.63 dark. A raw
  colour-pair check will not catch this: the ratio has to be computed on the
  colour BLENDED at its opacity. Disabled controls keep 0.55 (in
  `.brut-press:disabled`), which WCAG exempts and which should look disabled.
- **Hazard striping marks refusal only** - the demo disclosure and a refused
  turn. It stops being a warning the moment it becomes texture.
- Theme lives in the DOM via the pre-paint script in `layout.tsx`.
  `suppressHydrationWarning` on `<html>` is deliberate.
- Tokens live in `globals.css` under `@theme`. There is no `tailwind.config.ts`
  - this is native Tailwind v4.
- lucide-react v1 has no brand icons. `import { Github }` does not exist.
